# Week 3 - Advanced Data Analysis and Visualization in Logistics

This project performs exploratory data analysis (EDA) on the logistics sample dataset used in Week 2.

## Files
- `Week_3_Logistics_Advanced_Data_Analysis_Report.docx` - detailed report with visualizations and findings
- `week3_analysis.py` - Python EDA and visualization script
- `sample_logistics_data.csv` - dataset used for analysis
- PNG files - visualization outputs

## Key analysis
- Distribution and descriptive statistics
- Late-delivery rate by shipping mode
- Late-delivery rate by traffic level
- Distance vs order value relationship
- Correlation analysis

## Note
`actual_days` is treated as an outcome/post-delivery variable and is not used as a predictive feature for decision-making analysis, to avoid data leakage.
